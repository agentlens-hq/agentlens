How it works

Two lines to install. Then ask why.

Add AgentLens before your existing provider client. Nothing else changes — it patches Anthropic and OpenAI at import time and captures every call locally.

01

Initialize

One call patches your provider clients — sync, async, and streaming.

import agentlens
agentlens.init()
02

Run

Wrap your agent so every span groups into one run in .agentlens/runs/.

@agentlens.run(name="support_agent")
def run_agent(query):
    # your agent, unchanged
03

Diagnose

Root cause, the failed step, why, the fix, confidence, and cost.

$ agentlens diagnose <run_id>

Coverage
Works with what you already build on.

        
AgentLens captures at the provider layer, so it sees agents whether you write raw API calls or use a framework on top.

      

      

        

          
Native support

          
AnthropicOpenAILangGraphraw API

          
Instrumented directly. agentlens.init() patches the Anthropic and OpenAI clients; patch_langgraph() wraps a compiled graph.

        

        

          
Captured via underlying calls

          
CrewAIAutoGenPydanticAI

          
These frameworks run on Anthropic/OpenAI under the hood, so their calls are captured too. Framework-level spans are on the roadmap.

Real diagnoses
What a broken agent looks like, resolved.

        
Three failure shapes AgentLens catches — from what the agent did to the fix.

      

      

        

          tool_selection
          
did · asked for a local record, called search_web

          
broke · web has no private customer data

          
tool_selection @ 0.90 — fix: give the two tools distinct descriptions.

        

        

          loop
          
did · called query_db("alex") three times

          
broke · same tool + input, no exit condition

          
loop @ 0.95 — flagged at the origin step, not where you noticed it.

        

        

          cascade
          
did · used a stale tool result downstream

          
broke · bad upstream data corrupted the next step

          
cascade @ 0.90 — fix: validate the output before it's reused.
